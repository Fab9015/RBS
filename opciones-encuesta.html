Elige la opción que más te convence para la encuesta

Vota por el nuevo portón de acceso

Como parte de la propuesta para renovar el portón de acceso al condominio, se presentan 3 opciones para que la comunidad las conozca antes de participar en la encuesta de votación. Revisa las imágenes de cada opción y elige la que prefieras al momento de votar.

💡 Nota Las imágenes mostradas son de referencia. El resultado final puede variar ligeramente según disponibilidad de materiales y ajustes de instalación.

Opción 1 – Privacidad Sólida

Diseño, fabricación y montaje de sistema de herrería estructural para el control de acceso vehicular y peatonal. El proyecto se enfoca en el blindaje de áreas vulnerables y la conexión del sistema de identificación biométrica ya existente para maximizar la seguridad del residencial.

⚠️ Render solo ilustrativo (SOLO REFERENCIA). No incluye obra civil para techar el acceso ni construir como en la imagen.

  • Estructura principal: portón manual de dos hojas abatibles, fabricado en Acero A36 de alta resistencia.
  • Bastidores: PTR de alta durabilidad en Calibre 14, garantizando rigidez estructural ante el uso continuo.
  • Colocación de malla desplegada cal. 14 para visualización al centro del portón y acceso peatonal, herrajes para cierre de portón.
  • Silueta de árbol en corte láser al centro de los portones con el fin de dar mayor vista al acceso.
  • Herrajes y jaladeras para acceso peatonal y portones.
  • Soporte: postes de anclaje reforzados en Calibre 14 / calibre rojo, diseñados para soportar el torque y peso de las hojas sin deformaciones.
  • Revestimiento de perfil de acero 4" x 1.5" en la parte baja del portón para mayor privacidad y protección.
  • Instalación de secciones fijas en el área de caseta para sellar huecos.
  • Clausura del acceso izquierdo (visto de frente) para canalizar el flujo de forma segura.
  • Fabricación de puerta peatonal integrada, acondicionada y preparada específicamente para la integración de tecnología.
  • Acabado: aplicación de recubrimiento y acabado final color chocolate de grado industrial.

Opción 2 – Apariencia Vertical con Acero

Diseño jerarquizado que destaca por andador peatonal independiente con marco de acero, herrajes de seguridad y listones de perfil de acero de 4" x 1.5" colocados de manera vertical (R400).

  • Puerta de acceso peatonal con perfil de acero 4" x 1.5" cal. 18.
  • Base para ID facial para acceso peatonal.
  • Resorte para retorno de puerta peatonal.
  • Manija en acero para apertura de puerta peatonal.
  • Herrajes para cierre de portón.
  • Instalación de secciones fijas en el área de caseta para sellar huecos de seguridad.
  • Clausura del acceso izquierdo (visto de frente) para canalizar el flujo de forma segura.
  • Fabricación de puerta peatonal integrada, acondicionada y preparada específicamente para la integración de tecnología.
  • Acabado: aplicación de recubrimiento y acabado final color chocolate de grado industrial.
